Seguridad con Git

No ejecutes git reset --hard.

No ejecutes git clean -fd ni comandos que eliminen cambios locales.

No ejecutes git checkout -- . ni git restore . para descartar cambios.

No sobrescribas cambios existentes sin revisarlos y obtener autorización.

No hagas commits, merges, rebase ni push sin mi autorización explícita.

Antes de realizar operaciones que puedan afectar el historial o los cambios de Git, explica qué harás y solicita confirmación.

Cambios en el código

No reemplaces archivos completos cuando sea suficiente modificar una sección.

Conserva los cambios existentes realizados por otros desarrolladores.

Revisa los errores y las posibles consecuencias antes de terminar.

No afirmes que las pruebas pasaron si no las ejecutaste.

Al finalizar, resume los archivos modificados, los cambios realizados y las pruebas ejecutadas.

Interfaz y diseño

Conserva el diseño y la funcionalidad existentes, salvo que solicite expresamente modificarlos.

Mantén la consistencia visual y la responsividad.

Revisa que los textos tengan buena ortografía y no contengan caracteres corruptos.
